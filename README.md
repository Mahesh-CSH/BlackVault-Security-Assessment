# BlackVault

A local web application security assessment lab.

## Features
- Document search
- Document access controls
- Health-check endpoint
- JSON responses

## Requirements
- Python 3
- Flask 3.1.3

## Run locally

Install dependencies:

    python3 -m pip install -r requirements.txt

Start the application:

    python3 app.py

Open:

    http://127.0.0.1:5000/health

## Security testing

The tests directory contains automated tests.
The docs directory contains assessment documentation.
The evidence directory contains test screenshots.
